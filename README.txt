# Vaishnavi-wave Portfolio & Projects

All portfolio and project files are packaged in this single folder for easy access and deployment.

## Files Included
- `index.html`: Main portfolio website featuring your updated details, brand, and direct project links.
- `style.css`: Clean dark theme with responsive styling.
- `script.js`: Mobile menu and interaction handler.
- `calculator.html`: Universal Calculator web app.
- `number-converter.html`: Universal Number Converter web app.
- `decimal-to-binary.html`: Decimal to Binary Interactive Explorer web app.

## How to Run
1. Unzip this package.
2. Open `index.html` in any web browser.
3. Every project link opens directly without any broken URLs.
